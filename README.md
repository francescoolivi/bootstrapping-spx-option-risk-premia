# Bootstrapping Conditional Option Risk Premia on S&P 500 Index Options

Code for the Master's thesis *"Bootstrapping Conditional Option Risk Premia on S&P 500
Index Options"* (Francesco Olivi, Università Commerciale Luigi Bocconi, 2025/26).

The project applies the non-parametric bootstrapping framework of
[Wu (2025), *Bootstrapping Option Risk Premiums*](#references) to exchange-traded
S&P 500 (SPX) index options. Wu developed the framework for OTC FX options. The idea is to
forecast the **conditional risk premium** of delta-hedged option positions from the full
implied-volatility surface instead of an aggregate spread such as the conventional
variance risk premium ($VIX^2 - RV$). This needs no parametric model of the dynamics:
the forecast is the average P&L over many joint scenarios for the underlying and the
whole surface, built by resampling historical innovations.

## Method in brief

1. **Return innovation.** Daily SPX log-returns are scaled by the lagged 30-day ATM
   implied volatility, $\varepsilon_t = s_t / (I_{t-1}\sqrt{\Delta t})$. This removes
   most of the volatility clustering: AC(1) of squared returns falls from 0.31 to 0.03.
2. **IV innovations.** For each of 25 standardized options (deltas 10/25/50/75/90 ×
   maturities 30/91/182/273/365 days), log-IV changes are decomposed into a
   non-parametric, monotonicity-constrained mean-reverting drift $\mu(x)$ (local-linear
   kernel regression) and an innovation $\zeta$.
3. **Joint bootstrap.** At every test date, 10,000 one-week paths of the forward and of
   all 25 implied volatilities are generated by jointly resampling historical days of
   $(\varepsilon, \zeta_1,\dots,\zeta_{25})$. This preserves the cross-sectional
   dependence between returns and the whole surface.
4. **Conditional risk premium.** Each option is priced along each path (Black-76,
   discounted with the OptionMetrics zero curve) and delta-hedged daily. The mean
   simulated P&L is the forecast $\hat\eta_{j,t}$. The cross-path covariance gives a
   25 × 25 conditional covariance matrix.
5. **Out-of-sample evaluation.** Steps 2–4 are repeated every Wednesday from the sample
   midpoint, 773 dates from November 2010 to August 2025. All estimates (drift,
   innovations) use data up to each test date only, so there is no look-ahead. The forecasts
   are evaluated with expectation-hypothesis regressions (cross-sectional and
   time-series), Greek-based risk-premium attribution, mean-variance and vega-neutral
   portfolio strategies, and an encompassing test against the conventional VRP.

## Repository structure

```
├── notebooks/
│   └── bootstrapping_option_risk_premia.ipynb   # main, fully documented analysis (executed, with outputs)
├── scripts/
│   └── run_all.py                               # headless run: regenerates every table and figure
├── data/
│   └── README.md                                # how to obtain the (licensed) input data
├── output/                                      # tables (tab_*.csv), figures (fig_*.png), covariance matrices
├── requirements.txt
├── CITATION.cff
└── LICENSE
```

The notebook and the script share the same functions, parameters, and random seeds (42),
and produce identical numbers. Use the notebook to read the analysis step by step, with
commentary and interpretation. Use the script to regenerate all outputs. It also saves
every figure and runs the extra robustness diagnostics: drift bandwidth, alternative
return scaling, sub-samples, number of paths, HAC lags, and block vs. i.i.d. resampling.

## Data

The analysis uses OptionMetrics IvyDB US data (volatility surface, SPX prices, zero-coupon
yield curve, index dividends) via WRDS, plus the CBOE VIX series, for 1996-01-04 to
2025-08-29. **The data are licensed and are not included.** See
[`data/README.md`](data/README.md) for the exact files, sources, and columns.

## How to run

Python 3.10 or later.

```bash
git clone <repository-url>
cd bootstrapping-spx-option-risk-premia
python3 -m venv .venv && source .venv/bin/activate    # optional
pip install -r requirements.txt

# put the five input CSV files in data/  (see data/README.md)

# Option A — interactive notebook
cd notebooks && jupyter notebook bootstrapping_option_risk_premia.ipynb

# Option B — regenerate every table and figure in output/
python3 scripts/run_all.py
```

Runtime: about 6 minutes on a laptop for either option. Almost all of it is the
773-date rolling loop (773 dates × 10,000 paths × 25 options).

## Notes and limitations

- Options are **standardized synthetic contracts** from the OptionMetrics interpolated
  surface (fixed delta and maturity), not individual traded series. Bid-ask spreads and
  other trading frictions are not modelled.
- The horizon is 5 trading days, but a calendar week that contains a market holiday has
  only 4. Consecutive realized-P&L windows therefore sometimes overlap by one day: about
  18% of gaps between test dates are shorter than 5 trading days.
- Innovations are resampled i.i.d. The ζ innovations keep some residual volatility
  clustering. `scripts/run_all.py` (Section 15f) compares i.i.d. against block resampling.
